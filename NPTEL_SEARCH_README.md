# NPTEL Video Search Integration

This feature enables you to fetch lectures from NPTEL YouTube Playlists, cache them locally, search them via keywords, and perform concept-based semantic search using Google Gemini Embeddings (`text-embedding-004`).

---

## 📁 File Structure & Overview

*   [`src/data/nptel-playlists.json`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/data/nptel-playlists.json): Stores the list of NPTEL playlist IDs and their course names.
*   [`scripts/fetchVideos.js`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/scripts/fetchVideos.js): Downloads course video details (title, description, thumbnails) using the YouTube Data API v3.
*   [`src/data/videos.json`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/data/videos.json): The local JSON database generated by the fetch script.
*   [`scripts/embedVideos.js`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/scripts/embedVideos.js): Generates vector embeddings for all cached videos using Gemini's `text-embedding-004`.
*   [`src/data/nptel-vectors.json`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/data/nptel-vectors.json): The vector database file generated by the embed script.
*   [`src/app/api/nptel/videos/route.ts`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/app/api/nptel/videos/route.ts): Endpoint returning all cached NPTEL videos.
*   [`src/app/api/nptel/search/route.ts`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/app/api/nptel/search/route.ts): Search endpoint supporting both standard substring matches and Cosine Similarity semantic search.
*   [`src/app/nptel-search/page.tsx`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/app/nptel-search/page.tsx): Responsive search UI styled with the Academic Sanctuary light theme.

## 🚀 Setup & Execution

### 1. Configure Environment Variables
Add your YouTube API Key to your `.env.local` file (already configured for the Gemini key):
```env
YOUTUBE_API_KEY=your_youtube_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. Configure NPTEL Playlists
Open [`src/data/nptel-playlists.json`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/data/nptel-playlists.json) and add any NPTEL courses you want to index:
```json
[
  {
    "id": "PLAYLIST_ID_1",
    "courseName": "Name of Course 1"
  },
  {
    "id": "PLAYLIST_ID_2",
    "courseName": "Name of Course 2"
  }
]
```

### 3. Fetch Video Data
Run the fetch script to retrieve all video records from YouTube:
```bash
node scripts/fetchVideos.js
```
This generates [`src/data/videos.json`](file:///Users/sujalvikasgavshete/Documents/GitHub/Nova/src/data/videos.json).

### 4. Generate Embeddings (RAG / Semantic Search)
Run the embed script to convert video titles/descriptions into 768-dimensional vectors:
```bash
node scripts/embedVideos.js
```
*Note: This script will automatically skip videos that have already been embedded, saving your API rate limits and quota.*

### 5. Start Application
Launch your development server:
```bash
npm run dev
```
Navigate to `http://localhost:3000/nptel-search` to start searching!
